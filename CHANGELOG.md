## 1.0.0

- Initial release
- Hide-by-default architecture: CSS hides distractions at document_start
- 16 toggleable features across 4 groups:
  - **Feed & Recommendations:** Homepage feed, sidebar, end screen, Shorts, Mix/Radio
  - **Video Page:** Comments, description, live chat, merch/offers
  - **UI & Controls:** Video buttons, channel info, notification bell, annotations, playlist panel
  - **Behavior:** Disable autoplay
- Master toggle to enable/disable all blocking
- 4 themes: Retro Pink, Dark, Beige, Slate
- Settings page for advanced configuration
- Sparky mascot integration
- WCAG 2.1 AA accessible (all contrast checks pass)
- Privacy-first: local storage only, zero data collection
- Cross-browser support (Chrome + Firefox via gecko ID)
